# 极地四轮独立人工复核

依据冻结的 `tests/fixtures/behaviorScenarios.ts` 极地四轮预期，逐项读取 [真实记录](../final-live/polar-energy.json) 中的实际 before/after、原 NPC 输出、Resolver、已完成过程结算、审计和最终旁白。未调用模型裁判，未修改代码、预期或原始记录。机器可读结论见 [polar-energy.json](polar-energy.json)，其中 JSON Pointer 都指向上述真实记录。

| 回合 | 属性 | 旁白 | 总体 |
|---|---|---|---|
| 1 提供口粮 | 通过 | 通过 | 通过 |
| 2 只等一秒 | 通过 | 通过 | 通过 |
| 3 等待二十分钟 | 有争议 | 通过 | 有争议 |
| 4 命令满状态并瞬移 | 通过 | 通过 | 通过 |

第一轮只发生放下口粮、诺拉环顾与确认道谢，饥饿等属性没有凭邀请获益。旁白也没有擅自让她拆封吃饭。她先确认归属是可接受的角色选择，无须强制她立即进食。动作裁决曾以座椅和取暖器为依据额外写出“桌面”，但最终物品仅移至现场，旁白采用“够得到的地方”，没有把这项不充分依据变成新增实体或明确桌面事实。

第二轮实际等待一秒，另有玩家说话的一点五秒，因此时钟共前进二点五秒。原 NPC 提议简短应答，但程序估计二点零四秒而过滤；最终没有 NPC 动作或发言。旁白“等了一秒，诺拉仍在原处”准确，属性也没有凭休息建议恢复。这里没有要求 NPC 必须点头或坐下；一秒内保持原处符合预先允许的范围。Resolver 两次输出的提示误写“一分钟”，这是存在的中间错误，最终时钟和旁白均未采用，不能把它当成实际经过一分钟。

第三轮解决了此前“二十分钟却毫无生理变化”的主要问题：实际时钟推进 1200 秒，诺拉自主选择并获接受进食 60 秒、取暖器旁休息 900 秒、环顾 2 秒。预行动属性候选为空，实际执行后才结算：饥饿 0.8→0.65，疲劳 0.7→0.58，寒冷负担 0.6→约 0.45，健康仍 0.8。来源是已提交的自身动作，没有凭空造第二份口粮。

**但第三轮不能判完全通过。** 完整 `eat_item` 已令口粮 `consumed=true`；结算模型输入也明确看到了这个状态，其饥饿更新理由却说“实际进食了口粮约一分钟，缓解了一部分饥饿，**但未吃掉整份**”。审计同样拿到这两个冲突事实，仍返回 `valid=true`。旁白“吃完之后”与已提交消费状态一致，矛盾发生在属性结算的事实解释中。原预期没有规定一份食物的热量或饥饿必须下降多少，所以不能证明 -0.15 本身不合理；同时也不能忽略错误依据，仅因方向正确便算全部正确。故属性与总体列为有争议，而非擅自规定更大的降幅。

第三轮旁白的主要动作都有来源。拆封是吃密封食品所需的通常过程；“又合拢”“分量不多”以及墙上时钟是额外叙述细节，未成为新可操作物品或状态收益证据。未发现把未接受的进食、休息或说话写成完成。真实进食只有一分钟，旁白也没有声称吃了二十分钟；二十分钟是整个等待窗口。

第四轮两项不可能要求均作为普通世界内失败尝试，没有路由管理员，没有恢复满状态，也没有位移。诺拉可见的观察包含失败结果，并从自己的过去经历知道吃过、歇过；她只环顾，没有再次消费已耗尽食品。旁白正确写“两件事都没有发生”，没有替没有发言的 NPC 补话。

本结论是三个回合通过、一个回合有争议；不是四轮全部通过。第三轮的因果解释与完整消费状态冲突，是模型审计未抓到的剩余问题，原始记录应保留用于后续改进。
