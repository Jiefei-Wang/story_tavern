## 逐案例证据

**流向反转，三次失败。** 原事件 `turn_1_b0_event_0.outcome.summary` 明确物品从玩家移至现场，Patch 和当前实体均为 `/entities/pistol/location=test_room`。待审第 0 段却写“玩家伸手将桌上的训练手枪取到手中”。三份摘要都将这个错误方向复述为事实，例如第 2 次写“玩家从 table 取枪，pistol 位置变为 test_room”。错误 `source.op=take` 不能推翻已提交物理结果。摘要不仅未帮助发现错误，还混合了错误动作描述与正确末态。所有 answer 均无 issue。

**实物记录，三次失败。** 待审第 1 段为“夏岚低头看了一眼手边的记录，语气平稳”。公开实体没有该记录，NPC 公开事件只有按 SpeechPlan 回答，没有查看、取出或书写记录的动作。“按记录回答”支持对白内容，不能独立支持手边实物及已执行查看。第 1 次摘要写“无记录被移动或整理”，没有回答实物是否存在、查看动作是否有来源；第 2、3 次摘要只列正确的约定对白、已有实体和 clock 变化。三次均未命中第 1 段。正确的新旧约定对白不应被误报，本组也确实没有额外误报。

**失败尝试，三次通过。** 恢复状态、瞬移的公开结果均为 failed，待审文字也明确“两件事都没有发生”；诺拉环顾有成功 `glance_around` 支持。摘要正确区分两项失败和环顾成功。没有新增能力、物品或发言；普通寒冷环境修辞不构成需要拒绝的额外结果。三次 `grounded=true` 均符合证据。

**新接收范围，三次失败。** 第 0 段、实体 `raincoat.location=shen` 与三份摘要都说明雨衣仍在沈苒处；本次 give 失败。对应 SpeechPlan 是“刚才的递出动作没有成功，我并没有接到任何东西”，限制在本次赠予。第 3 段 speech 却变为“你刚才什么都没递过来，我手里也没有东西”。“本次没有新增”不能扩大为当前全部持有状态；无需进一步虚构雨衣究竟穿着还是握着。三次摘要都已抓到持有与本次失败的事实，answer 仍无任何 issue，尤其没有命中关键第 3 段。不能因为摘要提到雨衣、或假设第 0 段已修正，就判整个审查通过。
