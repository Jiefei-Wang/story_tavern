# 第三轮：在同一短摘要提示下，仅改变输入组织

沿用v2的旁白/旁白审查system提示、摘要输出格式、原模型与参数。只选8个有明确标准的案例，各3次candidate，共24次：两个旁白失败、两个旁白正确对照、三个审查漏检及一个正确审查对照。参照同案例v1/v2已有回复，不声称全新同期A/B。

输入仅作可复现的结构投影：当前场景、当前实体、本轮公开Patch分列；事件里的source与顶层完全相同字段只保留一次，不同值全部保留；把原始来源与实际outcome标为不同栏；SpeechPlan独立显示；待审输出单列为非事实来源。不加入期望答案，不补造起始位置、动作或角色知识，不从人工gold改写事实。结构转换代码仅位于实验脚本。

这轮要检查的是“信息重复、来源与结果混放”是否妨碍理解，而不是增加程序剧情检查或放宽金标准。原始数据、转换后的实际请求、回复和人工复核均保存。沿用v1门槛；有限案例成功仍需管线验证，未达标则保持实验状态。
