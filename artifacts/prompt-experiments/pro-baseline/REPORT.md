# DeepSeek V4 Pro 原请求复测

**仅换 Pro 没有修复这批问题。** 18 个固定请求各重复 3 次，共 54 次真实调用，人工复核明确通过 27 次；此前 Flash 原提示对照为 28 次。旁白审查和人物变化审查的漏检没有改善，不能据此把正式模型切到 Pro 并宣称问题解决。

## 对照结果

表内为人工复核通过数，分母包括失败与争议。

| 角色 | Flash 原提示 | Pro 原提示 | 观察 |
|---|---:|---:|---|
| 旁白生成 | 17/21 | 14/21 | 物品流向仍三次全错，仍有虚构翻书、纸面记录等问题 |
| 旁白审查 | 3/12 | 3/12 | 九份错误旁白全部漏检；三份正例正确放行 |
| 输入编译 | 2/6 | 4/6 | 取放方向案例改善；另一案例两次遗漏双手离桌等动作信息 |
| 人物变化审查 | 6/15 | 6/15 | 虚构共同过去、道歉次数错误仍各漏检三次 |
| 合计 | **28/54** | **27/54** | 没有观察到整体改善 |

Flash：28 通过、21 失败、5 争议。Pro：27 通过、24 失败、3 争议。争议保留原口径，未为了模型比较修改预期；尤其“证词疑虑”指向哪个声明的材料存在歧义，不能强行判成通过或失败。

Pro 的物品取放编译案例从没有明确通过变为 3/3 通过，但原旁白输入仍含错误 `source.op=take` 与正确物理结果的冲突，Pro 旁白三次仍跟随了错误方向。这说明某一上游案例的改善，不等于已验证整条链路修复。

## 这说明什么

核心失败仍是**语义与证据核对**：旁白审查 12 次都给出 `grounded=true, issues=[]`；人物变化审查 15 次都给出 `valid=true`。其中确有正例，但错误样本同样被放行。模型能输出可解析的结构，仍可能没有正确核对物理结果、过去经历或陈述范围。因此不能只靠 JSON 格式正确，或模型自称“审查通过”，判断功能正常。

现有解析器加 Schema 校验，两模型均通过 53/54。这个指标允许解析器从回复中提取 JSON，**不等于原始回复整段都是纯 JSON**。Pro 有一份旁白在 speech 中多输出 actor/target，导致 Schema 失败；也有审查回复在 JSON 前添加杂文。原始全文可直接解析为 JSON：Flash 53/54，Pro 38/54；其余可能带 Markdown 围栏或额外文字，这一项与 Schema 是否通过分开统计。两批每条调用均有 reasoning_tokens 计数，合计均为 0，与请求的 none 一致。

这些结果不能证明 Pro 在所有任务上更弱，也不能单独区分提示词、证据表达和模型能力各占多少原因。它们支持的结论是：**在这批相同请求、相同参数下，只换模型仍未解决主要漏检。** 正式代码、保存的 Agent 和 unit test 组绑定均未修改。

## 实验边界与证据

- 模型使用配置中已有的 [DeepSeek V4 Pro 0813 正式版](https://openrouter.ai/deepseek/deepseek-v4-pro-0813)，请求 ID 为 `deepseek/deepseek-v4-pro-0813`；对照为 `deepseek/deepseek-v4.1-flash`。
- 沿用 unit test 冻结配置，在内存中覆盖模型；保留原始 system/user 消息、输出 Schema、temperature、top_p、token 上限和 `reasoning_effort=none`。没有使用此前候选提示词、摘要包装或输入清理方案。
- 每次一次真实请求，没有格式重试或 Mock。18 个固定请求来自先前案例，包含多轮历史，但这是单步重放，未重新运行完整多轮游戏，也未重跑整个安全拒绝测试集。
- 每个案例只有三次重复，且 Flash 对照不是同期重跑，不能将 54 次视作 54 个独立故事或统计上稳定的模型排名。
- [summary.json](summary.json) 由 scripts/summarize_pro_replay.ts 汇总人工结论，同时断言消息、Schema、原始证据与配置未变、请求参数只有 model 变化、生产源码指纹未变。
- [manifest.json](manifest.json) 保存实际请求；[completed.json](completed.json) 保存完成及不变性记录；responses 目录保留每一次原始回复、解析结果与 trace。
- 逐条人工复核：[旁白生成](narration-review.md)、[旁白审查](auditor-review.md)、[输入编译与人物审查](reasoning-review.md)。
